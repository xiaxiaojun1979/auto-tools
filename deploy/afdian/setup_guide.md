3. 用手机号注册
4. 注册完成后告诉我账号名

## 你只需在爱发电上操作
你注册好后，按以下步骤操作即可（每一步我都有截图指引）：

### 步骤1：创建发电页
1. 登录后点击「我的」→「创作中心」
2. 点击「创建新发电」
3. 按 products_config.json 的内容填写

### 步骤2：上传文件
```bash
# 对每个产品，执行以下命令打包文件
# 文件批处理大师：
cd /Users/tianmengpiaoxiang/Desktop/automation_business
tar -czf deploy/afdian/file_tools_package.tar.gz \
  -C products/file_tools main.py README.md
# 然后在爱发电上传这个 tar.gz 文件
```

### 步骤3：设置自动发货
在爱发电编辑产品时，开启「购买后自动发送文件」

### 步骤4：提现配置
在「我的」→「收益设置」中绑定：
- 支付宝收款（实时到账）
- 或微信支付
